# 7-01 End-to-end tests

Status: Built · 6 Nov 2026
Kind: new · Spec: 2a (the no-store check), 4, 5 · Depends on: 5-03, 6-03

## Decide
- Playwright runs against a real `next build && next start`, connected to a **memory MongoDB**: never `aem-dev` or `aem-prod`, so it runs in CI with no secrets.
- Three specs:
  - **no-store on every page and API route** (the check the spec promises);
  - the household flow, on a phone-sized screen;
  - the admin flow.
- No blocking questions.

**`scripts/e2e.ts`:**
1. Start a `MongoMemoryReplSet`, then `startTestDb({ uri })`, `seedBasic()` and `invite("sample-rsvp", ["10000001","10000002"])`, then disconnect mongoose.
2. Run `next build`.
3. Spawn `next start -p 3100` with env `MONGODB_URI=<uri>`, `MONGODB_DBNAME=aem-dev` and `JWT_SECRET=e2e-secret-e2e-secret-e2e-secret-1`.
4. Poll `http://localhost:3100/api/v1/health` until it returns 200 (60 s max).
5. Run `npx playwright test`.
6. Kill the server and stop the DB in `finally`, and exit with Playwright's code.
